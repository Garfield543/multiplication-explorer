# 「2、5、4、8 的乘法」互動學習網頁

供國小低年級學生在瀏覽器練習 2、5、4、8 的乘法，可用於課堂操作及個別練習。

## 教師使用說明

用 Chrome 或 Edge 開啟 `index.html`，按「開始探索」。有本機紀錄時，可用「繼續學習」回到最近的步驟。

1. **建立一組**　先拖曳蘋果到第 1 籃，也可以先點蘋果，再按「放入」。完成第 1 籃後，會出現第 2 籃。取出或復原可用來修正數量。
2. **倍數魔法**　按按鈕增減整籃。先猜總數，確認後再看連加與倍數。
3. **乘法變身術**　先辨認每籃數量、籃數和總數，再用數字卡拼算式。可點選欄位修改。
4. **自由探索**　前三站完成後解鎖。建議按 2、5、4、8 的順序練習。每種乘法從建立一組開始，經過連加、倍數、列式，再到生活題。
5. **生活小店**　完成四種乘法後解鎖。對照各袋糖果或各盒蛋糕的數量，先判斷照目前的分組能不能直接用一道乘法求總數，再列式或用加法算總數。
6. **多一組、少一組**　完成生活小店後解鎖。用優格和章魚燒練習列式、增減一組後的總數，以及比較兩個算式相差幾個一組。既有的後段練習進度仍可繼續。
7. **綜合練習**　混合 2、5、4、8 的乘法列式與組數比較。最後用書架題判斷怎麼算，並回顧「看各組是否一樣多、找每組數量和組數、求總數」的解題步驟。

教學路線依 Gemini 設計稿轉述的教師手冊流程編排。老師可用「老師模式」依課次指定學習站。

「學習設定」可以開關注音、自動讀題、慢速朗讀及減少動畫，也能切換基礎或進階模式。「老師模式」可以直接進入學習站、設定探索單位量與組數上限、切換顯示方式，或重設本機進度。畫圖區可畫點、圈組、擦除及復原，由學生或老師查看。

## 驗收與限制

- 本次改版另用桌面 Chrome 驗證生活小店的四題判斷與計算、答錯重試、乘法算式順序、後續解鎖、儲存的作答階段，以及綜合練習最後一題與統整畫面。測試透過預先建立概念站與部分自由探索進度進入新流程。

- 已用桌面 Chrome 自動測試本機單檔開啟、滑鼠拖曳、點選放入、取回錯誤作答後重試、算式順序、自由探索解鎖、四種乘法各練到 9 組，以及重新整理後的進度與注音偏好。另檢查 320、390、768、1024、1440 像素寬度的探索畫面，並確認老師面板與畫布可開啟。
- 朗讀取決於裝置的中文語音。實機朗讀、平板觸控與螢幕閱讀器尚待課堂驗證。
- 注音以此教材的有限文字與詞組讀音表產生。自動測試檢查已走過的畫面沒有空白注音，完整逐詞校讀尚未完成。
- 教材由單一 HTML 提供，核心操作可離線使用。學習進度儲存在目前瀏覽器，畫圖留在當次開啟的頁面。
